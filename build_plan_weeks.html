Local LLM Code Review API — Build Plan

5-week plan · Node.js · Ollama · PostgreSQL · Jest · AWS

Week 1 Foundation — Node.js + Express API

Daily goals

Day 1–2: Install Node.js, init project with npm, build your first "hello world" Express server

Day 3–4: Build POST /review route, accept JSON body, return a mock response

Day 5–7: Add API key auth middleware, input validation with Zod or Joi

Resume checkbox

✓ Node.js REST API

✓ Back-end services development

✓ Secure software development practices

Deliverable by end of week

A running Express server that accepts a code diff and returns a JSON response. Pushed to GitHub with a README.

Week 2 AI Integration — Ollama + LLM prompt engineering

Daily goals

Day 1–2: Install Ollama, pull Mistral or LLaMA 3, run it locally via CLI

Day 3–4: Call Ollama's HTTP API from Node.js, pipe the code diff as context

Day 5–7: Engineer a structured prompt — get the model to return JSON with issues, severity, and suggestions

Resume checkbox

✓ AI/LLM integration (self-hosted)

✓ Emerging technology research + recommendation

✓ Translating requirements into code

Deliverable by end of week

POST /review sends a real diff to Ollama and returns structured AI feedback. End-to-end working locally.

Week 3 Database — PostgreSQL + SQL

Daily goals

Day 1–2: Install PostgreSQL, design schema — reviews, users, audit_log tables

Day 3–4: Connect Node.js to DB using pg or Prisma ORM, write DB helper functions

Day 5–7: Add GET /reviews history endpoint, paginated query, add rate limiter

Resume checkbox

✓ Database design (PostgreSQL)

✓ SQL queries + schema design

✓ Back-end services with persistent storage

Deliverable by end of week

Every review is stored in PostgreSQL. You can fetch review history by user. Schema is versioned with migrations.

Week 4 Testing — Jest unit + integration tests

Daily goals

Day 1–2: Install Jest + Supertest, write unit tests for all validators and controllers

Day 3–4: Write integration tests for every route — happy path + edge cases (bad input, no auth, empty diff)

Day 5–7: Write a test plan document, hit >80% code coverage, add coverage badge to README

Resume checkbox

✓ Testing frameworks (Jest)

✓ Complex test plans — designed and executed

✓ Debugging and troubleshooting

Deliverable by end of week

Full Jest test suite. A written test plan document. Coverage report showing >80%. All green on CI.

Week 5 Cloud deployment — Docker + AWS EC2 + RDS

Daily goals

Day 1–2: Write a Dockerfile for the API, docker-compose for API + Ollama + Postgres locally

Day 3–4: Provision AWS EC2 (free tier), push image, configure environment variables and security groups

Day 5–7: Migrate DB to AWS RDS, set up IAM roles, write deployment docs, finalize README

Resume checkbox

✓ Cloud deployment (AWS EC2 + RDS)

✓ Docker containerization

✓ Deployment planning + feedback mechanisms

Deliverable by end of week

A live URL on AWS. Anyone can POST a code diff and get an AI review back. Fully documented on GitHub.
